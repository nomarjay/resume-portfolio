# Jordan King - Portfolio Website

A modern, responsive one-page portfolio website showcasing my skills, education, projects, and contact information. Built with a focus on accessibility (WCAG 2.1 AA compliance) and SEO optimization.

## 🌐 Live Demo

Visit the live site: [www.jordanking.io](https://www.jordanking.io)

## 📋 Features

- **Responsive Design** - Fully responsive across all devices (mobile, tablet, desktop)
- **Dark Theme** - Modern dark color scheme with purple accent colors
- **SEO Optimized** - Comprehensive meta tags, Open Graph, Twitter Cards, and structured data
- **WCAG 2.1 AA Compliant** - Accessible design with proper ARIA labels, semantic HTML, and keyboard navigation
- **Smooth Scrolling** - Navigation with smooth scroll-to-section functionality
- **Interactive Elements** - Hover effects, focus states, and animated transitions
- **Contact Form** - Functional contact form for inquiries

## 🛠️ Technologies Used

### Frontend
- **HTML5** - Semantic markup
- **CSS3** - Custom properties (CSS variables), Flexbox, Grid
- **JavaScript** - Interactive functionality
- **Bootstrap 5.3.8** - Responsive framework
- **Font Awesome 6.4.0** - Icons

### Libraries & Frameworks
- jQuery 3.7.1
- Bootstrap Bundle JS

## 🚀 Getting Started

### Prerequisites
- Modern web browser
- Text editor (VS Code, Sublime, etc.)
- Local server (optional, for development)

### Installation

1. Clone the repository
```bash
git clone https://github.com/nomarjay/portfolio.git
```

2. Navigate to the project directory
```bash
cd portfolio
```

3. Open `index.html` in your browser or use a local server
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server
```

4. Visit `http://localhost:8000` in your browser

## 🔧 Customization

### Update Personal Information

1. **Meta Tags** - Update SEO information in `<head>`
2. **Hero Section** - Modify name, title, and description
3. **Education** - Add/remove education entries
4. **Skills** - Update skill badges with your technologies
5. **Projects** - Replace with your own projects
6. **Contact Info** - Update email, location, and social links

### Modify Colors

Edit CSS variables in `style.css`:
```css
:root {
    --accent: #your-color;
    /* Add your custom colors */
}
```
